# Review request: tampering test driver for the SPQR runtime monitor

Repository: the current directory (Rust crate `spqr` plus Lean 4 monitor under `Monitor/`). You can read any file.

## Context
A runtime monitor (cargo feature `monitor`) logs each party's `States::send`/`States::recv` calls and primitive calls (HKDF, HMAC, ML-KEM, decoder results) as JSON lines (`src/monitor.rs`). The Lean program `Monitor/Main.lean` + `Monitor/Check.lean` replays each party through a verified checker `BraidModel.checkRun` (`Spqr/Specs/Braid/StateMachine/Monitor.lean`). It has `Obs.recvErr`: a failed code `recv` is accepted only when the model's `Receive()` also fails, and the state stays. `sessionChecks` (Check.lean) checks delivery: each received message must equal an unconsumed earlier send of the peer.

## Goal of the change (commit f6e62a5, `git show f6e62a5`)
Mutant R4 (`let _ = auth.verify_ct(epoch, &ct1, &mac);` instead of `...?;` in `src/v1/unchunked/send_ek.rs`) passes `cargo test` and the monitor accepted its honest traces, because honest runs never deliver a bad MAC. The change adds adversarial tests so that the monitor sees a failing MAC:

- `src/test/orchestrator/tamper.rs`: `tamper_chaos` (chaos driver; for a Hdr chunk in NoHeaderReceived or a Ct2 chunk in EkSentCt1Received of the same epoch, with probability 0.3, a dry run of `recv` on a clone of the receiver's `States`, events paused, with the honest chunk; if it changes state name or epoch, the chunk completes the decoder; then one random byte of a copy is XORed, a `tamper` event is logged, the copy delivered; error expected; original delivered afterwards; if the copy is accepted the original is dropped). `tamper_early` (short sessions, in-order delivery; the first non-completing Hdr/Ct2 chunk of a decoding state is replaced by a tampered copy; the victim then fails at every later decode of that epoch; errors of the victim are tolerated; asserts at least one victim error and key agreement).
- `src/monitor.rs`: `paused`, `emit_at`, `tamper` (event in the operation number of the following recv).
- `src/test/messaging_scka.rs`: `scka()` accessor.
- `Monitor/Check.lean`: `tamperedCopy` and handling of `tamper` events in `sessionChecks`: original must be an unconsumed send of the peer; copy same epoch, payload kind, chunk index, chunk length, different bytes; then the copy counts as one more send of the peer.
- `src/v1.rs`: two tests under `#[cfg(feature = "monitor")]`.

Out of scope: changing BraidModel or the theorems.

+//! Test drivers that tamper with `Hdr` and `Ct2` chunks in transit, for the runtime monitor
+//! (feature `monitor`).
+//!
+//! Honest runs never deliver a bad MAC, so a monitor of honest traces cannot see a MAC check
+//! whose result the code ignores. These drivers deliver tampered chunks and log each one with a
+//! `tamper` event (`crate::monitor::tamper`). A `recv` that fails leaves the party in its old
+//! state (`GenericMessagingScka::messaging_scka_recv` keeps the old state on an error), and the
+//! run goes on.
+//!
+//! - `tamper_chaos` tampers with chunks that complete a decoder, so that the honest code fails
+//!   at the MAC check of that `recv`, and then delivers the original chunk.
+//! - `tamper_early` tampers with a chunk that does not complete the decoder. The honest code
+//!   accepts it and keeps it in the decoder, and every later decode of that epoch fails at the
+//!   MAC check: the party stays in that epoch for the rest of the session.
+//!
+//! Whether a chunk completes the decoder comes from a dry run on a clone of the receiver's
+//! state with the honest chunk and no events written. The dry run does not depend on the MAC
+//! check of a tampered chunk.
+

+/// A copy of `m`.
+fn copy_msg(m: &Message) -> Message {
+    let payload = match &m.payload {
+        MessagePayload::None => MessagePayload::None,
+        MessagePayload::Hdr(c) => MessagePayload::Hdr(*c),
+        MessagePayload::Ek(c) => MessagePayload::Ek(*c),
+        MessagePayload::EkCt1Ack(c) => MessagePayload::EkCt1Ack(*c),
+        MessagePayload::Ct1Ack(b) => MessagePayload::Ct1Ack(*b),
+        MessagePayload::Ct1(c) => MessagePayload::Ct1(*c),
+        MessagePayload::Ct2(c) => MessagePayload::Ct2(*c),
+    };
+    Message {
+        epoch: m.epoch,
+        payload,
+    }
+}

+/// The kinds of chunk that the drivers tamper with.
+#[derive(Clone, Copy, PartialEq, Debug)]
+enum Kind {
+    Hdr,
+    Ct2,
+}
+
+/// The kind of a `Hdr` or `Ct2` message.
+fn kind(m: &Message) -> Option<Kind> {
+    match &m.payload {
+        MessagePayload::Hdr(_) => Some(Kind::Hdr),
+        MessagePayload::Ct2(_) => Some(Kind::Ct2),
+        _ => None,
+    }
+}

+/// A copy of the `Hdr` or `Ct2` message `m` with one random byte of the chunk changed.
+fn tampered<R: CryptoRng>(m: &Message, rng: &mut R) -> Message {
+    let mut t = copy_msg(m);
+    let c: &mut Chunk = match &mut t.payload {
+        MessagePayload::Hdr(c) | MessagePayload::Ct2(c) => c,
+        _ => unreachable!("only Hdr and Ct2 chunks are tampered with"),
+    };
+    let i = rng.next_u32() as usize % c.data.len();
+    c.data[i] ^= rng.random_range(1..=255u8);
+    t
+}

+/// Whether `state` adds the chunk of `m` to its decoder: a `Hdr` chunk in `NoHeaderReceived`
+/// or a `Ct2` chunk in `EkSentCt1Received`, of the state's epoch. Other states that accept these
+/// chunks start a new decoder or ignore them.
+fn decodes(state: &States, m: &Message) -> bool {
+    matches!(
+        (crate::monitor::state_info(state), kind(m)),
+        (("NoHeaderReceived", ep), Some(Kind::Hdr))
+            | (("EkSentCt1Received", ep), Some(Kind::Ct2)) if ep == m.epoch
+    )
+}

+/// The result of a dry run of `recv` of `m` from `state`, with no events written: `None` when
+/// the `recv` fails, `Some(true)` when it changes the state's name or epoch, `Some(false)`
+/// otherwise.
+fn dry_run(state: &States, m: &Message) -> Option<bool> {
+    let pre = crate::monitor::state_info(state);
+    let r = crate::monitor::paused(|| state.clone().recv(m));
+    r.ok().map(|r| crate::monitor::state_info(&r.state) != pre)
+}

+/// The `chaos` driver, where each delivery of a `Hdr` or `Ct2` chunk that completes the
+/// decoder is tampered with probability `prob`.
+pub fn tamper_chaos<R: CryptoRng>(num_ticks: usize, prob: f64, rng: &mut R) -> Result<(), Error> {

+    let send_limit = 10;
+    let drop_message_prob = 0.1;
+    let mut stats = Stats::default();
+    let mut orchestrator = OrchestratorBase::<Cka>::new(rng)?;
+    for i in 0..num_ticks {
+        let use_alex = if i % 100 < 50 {
+            rng.random_bool(0.25)
+        } else {
+            rng.random_bool(0.75)
+        };

+            let qlen = orchestrator.qlen(use_alex);
+            if qlen > 0 {
+                let at = rng.next_u32() as usize % qlen;
+                orchestrator.receive_at_tampering(use_alex, at, prob, &mut stats, rng)?;
+            }
+        }
+        let num_to_send = rng.next_u32() % send_limit;
+        for _ in 0..num_to_send {
+            orchestrator.send(use_alex, rng)?;
+            if rng.random_bool(drop_message_prob) {
+                orchestrator.drop_message_at(use_alex, 0);
+            }
+        }
+        loop {
+            let qlen = orchestrator.qlen(use_alex);

+            }

+        }

+/// decoder is replaced by a tampered copy. In each tick one random party sends a message and the

+                } else {

+        );
+        assert!(victim_errors > 0, "session {s}: the victim never failed");
+    }
+    Ok(())
+}

   355	          if let some c := c? then
   356	            if c.index != enc.2 % 65536 || c.data.length != 32 then
   357	              return fail s!"operation {o.op}: parity chunk #{c.index} of {c.data.length} bytes, \
   358	                expected index {enc.2 % 65536} and 32 bytes" steps.size
   359	            match addParity T enc c, addParity all enc c with
   360	            | .ok t, .ok a => T := t; all := a
   361	            | .error err, _ | _, .error err => return fail s!"operation {o.op}: {err}" steps.size
   362	      | _, _ => pure ()
   363	      let Q := T.prims
   364	      match checkStep Q σ obs with
   365	      | some σ' => σ? := some σ'
   366	      | none =>
   367	        let why := explainStep Q σ obs
   368	        let other := if (why.splitOn "hmac").length > 1 && T.hmac.size > 0 then
   369	            s!" (this operation logged {T.hmac.size} hmac call(s), on other keys or data)"
   370	          else ""
   371	        firstFail := some s!"operation {o.op} (line {se.line}), {se.f} in {State.describe σ}, \
   372	          message {describeMsg (obsMsg obs)}: {why}{other}"
   373	        σ? := none
   374	    steps := steps.push (T.prims, obs)
   375	  -- the verdict of the verified checker
   376	  match checkRun σ0 steps.toList with
   377	  | some _ =>
   378	    if let some f := firstFail then
   379	      return fail s!"internal: the learning pass failed but checkRun accepts: {f}" steps.size
   380	    ⟨party, steps.size, .ok (), obsKeys (steps.toList.map (·.2))⟩
   381	  | none =>
   382	    fail (firstFail.getD "rejected (no diagnosis)") steps.size
   383	
   384	/-- The result of the session-level checks. -/
   385	structure SessionChecks where
   386	  delivery : Except String Unit
   387	  keys : Except String Unit
   388	  incompleteEpochs : List Nat
   389	  randomness : Except String Unit
   390	
   391	/-- Whether `t` is a tampered copy of `m`: a chunk message with the same epoch, payload kind,
   392	chunk index and chunk length, and other chunk bytes. -/
   393	def tamperedCopy (m t : Msg MChunk) : Bool :=
   394	  let chunk : Payload MChunk → Option MChunk
   395	    | .hdr c | .ek c | .ekCt1Ack c | .ct1 c | .ct2 c => some c
   396	    | _ => none
   397	  match chunk m.payload, chunk t.payload with
   398	  | some c, some d =>
   399	    m.epoch == t.epoch && m.payload.ctorIdx == t.payload.ctorIdx && c.index == d.index &&
   400	      c.data.length == d.data.length && c.data != d.data
   401	  | _, _ => false
   402	
   403	/-- Delivery, key agreement and reuse of randomness for a session's events, in file order.
   404	
   405	Delivery: each receive consumes an equal earlier send of the other party. A `tamper` event of a
   406	party, with arguments `[orig, copy]`, says that the network made `copy` from `orig` and that the
   407	party receives `copy` next. `orig` must be an earlier send of the other party that no receive
   408	consumed, and `copy` a tampered copy of it (`tamperedCopy`). Then `copy` counts as one more send
   409	of the other party. `orig` stays available. -/
   410	def sessionChecks (evs : Array Event) (ka kb : List Key) : SessionChecks := Id.run do
   411	  -- delivery: each receive consumes an equal earlier send of the other party
   412	  let mut sent : HashMap (String × String) Nat := {}
   413	  let mut delivery : Except String Unit := .ok ()
   414	  let mut seen : HashSet String := {}
   415	  let mut randomness : Except String Unit := .ok ()
   416	  for e in evs do
   417	    if e.f == "States::send" then
   418	      if let .ok m := e.ret.getObjVal? "msg" then
   419	        let k := (e.party, m.compress)
   420	        sent := sent.insert k (sent.getD k 0 + 1)
   421	    else if e.f == "States::recv" && delivery.isOk then
   422	      if let some m := e.args[2]? then
   423	        let peer := if e.party == "A" then "B" else "A"
   424	        let k := (peer, m.compress)
   425	        match sent[k]? with
   426	        | some (n + 1) => sent := sent.insert k n
   427	        | _ => delivery := .error s!"line {e.line}: party {e.party} received a message that \
   428	            party {peer} did not send"
   429	    else if e.f == "tamper" && delivery.isOk then
   430	      let peer := if e.party == "A" then "B" else "A"
   431	      match e.args[0]?, e.args[1]? with
   432	      | some o, some t =>
   433	        match parseMsg o, parseMsg t with
   434	        | .ok mo, .ok mt =>
   435	          if sent.getD (peer, o.compress) 0 == 0 then
   436	            delivery := .error s!"line {e.line}: party {e.party} received a tampered copy of a \
   437	              message that party {peer} did not send"
   438	          else if !tamperedCopy mo mt then
   439	            delivery := .error s!"line {e.line}: the tampered message differs from the original \
   440	              in more than the chunk bytes"
   441	          else
   442	            let kt := (peer, t.compress)
   443	            sent := sent.insert kt (sent.getD kt 0 + 1)
   444	        | _, _ => delivery := .error s!"line {e.line}: bad message in a tamper event"
   445	      | _, _ => delivery := .error s!"line {e.line}: a tamper event needs two messages"
   446	    else if (e.f == "mlkem.generate" || e.f == "mlkem.encaps1") && randomness.isOk then
   447	      let i := if e.f == "mlkem.generate" then 0 else 1
   448	      if let some r := e.args[i]? then
   449	        let s := r.compress
   450	        if seen.contains s then
   451	          randomness := .error s!"line {e.line}: {e.f} reuses randomness of an earlier call"
   452	        seen := seen.insert s
   453	  -- keys: at most one per epoch and party, equal where both parties have one
   454	  let toMap (ks : List Key) : Except String (HashMap Nat Bytes) :=
   455	    ks.foldlM (init := {}) fun m (ep, s) =>
   456	      if m.contains ep then .error s!"two keys for epoch {ep}" else .ok (m.insert ep s)
   457	  let keys : Except String Unit × List Nat := match toMap ka, toMap kb with
   458	    | .error err, _ => (.error s!"party A: {err}", [])
   459	    | _, .error err => (.error s!"party B: {err}", [])
   460	    | .ok ma, .ok mb =>
   461	      let eps := (ma.keys ++ mb.keys).eraseDups.mergeSort
   462	      eps.foldl (init := (.ok (), [])) fun (r, inc) ep =>
   463	        match ma[ep]?, mb[ep]? with
   464	        | some a, some b => if a == b || !r.isOk then (r, inc)
   465	          else (.error s!"epoch {ep}: the parties' secrets differ", inc)
   466	        | _, _ => (r, inc ++ [ep])
   467	  ⟨delivery, keys.1, keys.2, randomness⟩
   468	
   469	end Monitor

   391	/-- Whether `t` is a tampered copy of `m`: a chunk message with the same epoch, payload kind,
   392	chunk index and chunk length, and other chunk bytes. -/
   393	def tamperedCopy (m t : Msg MChunk) : Bool :=
   394	  let chunk : Payload MChunk → Option MChunk
   395	    | .hdr c | .ek c | .ekCt1Ack c | .ct1 c | .ct2 c => some c
   396	    | _ => none
   397	  match chunk m.payload, chunk t.payload with
   398	  | some c, some d =>
   399	    m.epoch == t.epoch && m.payload.ctorIdx == t.payload.ctorIdx && c.index == d.index &&
   400	      c.data.length == d.data.length && c.data != d.data
   401	  | _, _ => false
   402	
   403	/-- Delivery, key agreement and reuse of randomness for a session's events, in file order.
   404	
   405	Delivery: each receive consumes an equal earlier send of the other party. A `tamper` event of a
   406	party, with arguments `[orig, copy]`, says that the network made `copy` from `orig` and that the
   407	party receives `copy` next. `orig` must be an earlier send of the other party that no receive
   408	consumed, and `copy` a tampered copy of it (`tamperedCopy`). Then `copy` counts as one more send
   409	of the other party. `orig` stays available. -/
   410	def sessionChecks (evs : Array Event) (ka kb : List Key) : SessionChecks := Id.run do
   411	  -- delivery: each receive consumes an equal earlier send of the other party
   412	  let mut sent : HashMap (String × String) Nat := {}
   413	  let mut delivery : Except String Unit := .ok ()
   414	  let mut seen : HashSet String := {}
   415	  let mut randomness : Except String Unit := .ok ()
   416	  for e in evs do
   417	    if e.f == "States::send" then
   418	      if let .ok m := e.ret.getObjVal? "msg" then
   419	        let k := (e.party, m.compress)
   420	        sent := sent.insert k (sent.getD k 0 + 1)
   421	    else if e.f == "States::recv" && delivery.isOk then
   422	      if let some m := e.args[2]? then
   423	        let peer := if e.party == "A" then "B" else "A"
   424	        let k := (peer, m.compress)
   425	        match sent[k]? with
   426	        | some (n + 1) => sent := sent.insert k n
   427	        | _ => delivery := .error s!"line {e.line}: party {e.party} received a message that \
   428	            party {peer} did not send"
   429	    else if e.f == "tamper" && delivery.isOk then
   430	      let peer := if e.party == "A" then "B" else "A"
   431	      match e.args[0]?, e.args[1]? with
   432	      | some o, some t =>
   433	        match parseMsg o, parseMsg t with
   434	        | .ok mo, .ok mt =>
   435	          if sent.getD (peer, o.compress) 0 == 0 then
   436	            delivery := .error s!"line {e.line}: party {e.party} received a tampered copy of a \
   437	              message that party {peer} did not send"
   438	          else if !tamperedCopy mo mt then
   439	            delivery := .error s!"line {e.line}: the tampered message differs from the original \
   440	              in more than the chunk bytes"
   441	          else
   442	            let kt := (peer, t.compress)
   443	            sent := sent.insert kt (sent.getD kt 0 + 1)
   444	        | _, _ => delivery := .error s!"line {e.line}: bad message in a tamper event"
   445	      | _, _ => delivery := .error s!"line {e.line}: a tamper event needs two messages"
   446	    else if (e.f == "mlkem.generate" || e.f == "mlkem.encaps1") && randomness.isOk then
   447	      let i := if e.f == "mlkem.generate" then 0 else 1
   448	      if let some r := e.args[i]? then
   449	        let s := r.compress
   450	        if seen.contains s then
   451	          randomness := .error s!"line {e.line}: {e.f} reuses randomness of an earlier call"
   452	        seen := seen.insert s
   453	  -- keys: at most one per epoch and party, equal where both parties have one
   454	  let toMap (ks : List Key) : Except String (HashMap Nat Bytes) :=
   455	    ks.foldlM (init := {}) fun m (ep, s) =>
   456	      if m.contains ep then .error s!"two keys for epoch {ep}" else .ok (m.insert ep s)
   457	  let keys : Except String Unit × List Nat := match toMap ka, toMap kb with
   458	    | .error err, _ => (.error s!"party A: {err}", [])
   459	    | _, .error err => (.error s!"party B: {err}", [])

   461	      let eps := (ma.keys ++ mb.keys).eraseDups.mergeSort

   463	        match ma[ep]?, mb[ep]? with

   465	          else (.error s!"epoch {ep}: the parties' secrets differ", inc)
   466	        | _, _ => (r, inc ++ [ep])

     8	/-! # `spqr-monitor`: check event logs against `BraidModel`
     9	
    10	Usage: `spqr-monitor [--max-ops N] <trace.jsonl>...`
    11	
    12	For each file and each session in it, the program checks both parties (`Monitor.checkParty`)
    13	and the session-level properties (`Monitor.sessionChecks`), and prints one line per party and
    14	per check. With `--max-ops N` it checks only the events up to the `N`-th operation of each
    15	session, and says so: that is partial coverage of the file. The exit code is 0 when every
    16	check of every file passes, 3 when every check passes on a prefix (`--max-ops`), and 1
    17	otherwise. -/

    19	open Lean Std Monitor
    20	
    21	/-- Read a file into events. -/
    22	def readEvents (path : String) : IO (Array Event) := do
    23	  let text ← IO.FS.readFile path
    24	  let mut evs : Array Event := #[]
    25	  let mut n := 0
    26	  for line in text.splitOn "\n" do
    27	    n := n + 1
    28	    if line.isEmpty then continue
    29	    match parseEvent n line with
    30	    | .ok e => evs := evs.push e
    31	    | .error err => throw (IO.userError s!"{path}:{n}: {err}")
    32	  return evs
    33	
    34	/-- Print the result of a session check; return whether it passed. -/
    35	def report (s : Nat) (what : String) (r : Except String Unit) : IO Bool := do
    36	  match r with
    37	  | .ok () => IO.println s!"  session {s} {what}: ok"; return true
    38	  | .error err => IO.println s!"  session {s} {what}: FAILED: {err}"; return false
    39	
    40	/-- Check one file; return whether every check passed. -/
    41	def checkFile (path : String) (maxOps : Option Nat) : IO Bool := do
    42	  let evs ← readEvents path
    43	  let sessions := (evs.map (·.session)).toList.eraseDups
    44	  let mut ok := true
    45	  IO.println s!"{path}: {evs.size} events, {sessions.length} session(s)"
    46	  if sessions.isEmpty then
    47	    IO.println "  REJECTED: no events"
    48	    return false
    49	  for s in sessions do
    50	    let mut sevs := evs.filter (·.session == s)
    51	    if let some n := maxOps then
    52	      let cut := sevs.filter (·.op ≤ n)
    53	      if cut.size < sevs.size then
    54	        IO.println s!"  session {s}: PARTIAL, only operations 0..{n} of this session are checked"
    55	        -- keep whole operations only
    56	        sevs := cut
    57	    -- only parties A and B; operations numbered 0, 1, 2, ... in file order
    58	    let mut last := 0
    59	    for e in sevs do
    60	      if e.party != "A" && e.party != "B" then
    61	        ok := false
    62	        IO.println s!"  session {s}: REJECTED: line {e.line}: unknown party {e.party}"
    63	        break
    64	      if e.op != last && e.op != last + 1 then
    65	        ok := false
    66	        IO.println s!"  session {s}: REJECTED: line {e.line}: operation {e.op} after \
    67	          operation {last}"

   148	    fn lagrange_interpolate_prepare(pts: &[Pt]) -> Self {

    31	/-- The value of a hex digit. -/
    32	def hexDigit (c : Char) : Option Nat :=
    33	  if '0' ≤ c ∧ c ≤ '9' then some (c.toNat - '0'.toNat)
    34	  else if 'a' ≤ c ∧ c ≤ 'f' then some (c.toNat - 'a'.toNat + 10)
    35	  else none
    36	
    37	/-- The bytes of a lowercase hex string. -/
    38	def decodeHex (s : String) : Except String Bytes := do
    39	  let rec go : List Char → Array Std.U8 → Except String (Array Std.U8)
    40	    | [], acc => .ok acc
    41	    | a :: b :: rest, acc =>
    42	      match hexDigit a, hexDigit b with
    43	      | some x, some y => go rest (acc.push (byte (16 * x + y)))
    44	      | _, _ => .error s!"bad hex digit in {s.take 16}"
    45	    | [_], _ => .error "odd number of hex digits"
    46	  return (← go s.toList #[]).toList
    47

    49	def jBytes (j : Json) : Except String Bytes := do decodeHex (← j.getStr?)

    52	def jNat (j : Json) : Except String Nat := j.getNat?

    76	def parseLabel (s : String) : Except String Label :=
    77	  match s with

    79	  | "KeysSampled" => .ok .keysSampled

    81	  | "Ct1Received" => .ok .ct1Received
    82	  | "EkSentCt1Received" => .ok .ekSentCt1Received
    83	  | "NoHeaderReceived" => .ok .noHeaderReceived
    84	  | "HeaderReceived" => .ok .headerReceived
    85	  | "Ct1Sampled" => .ok .ct1Sampled
    86	  | "EkReceivedCt1Sampled" => .ok .ekReceivedCt1Sampled
    87	  | "Ct1Acknowledged" => .ok .ct1Acknowledged
    88	  | "Ct2Sampled" => .ok .ct2Sampled

    91	/-- A chunk `{index, data}`. -/
    92	def parseChunk (j : Json) : Except String MChunk := do
    93	  return ⟨← jNat (← j.getObjVal? "index"), ← jBytes (← j.getObjVal? "data")⟩
    94	
    95	/-- A message `{epoch, kind, ...}`. As in `absMsg` (`Relation.lean`), `Ct1Ack(false)` is the
    96	`None` payload. -/
    97	def parseMsg (j : Json) : Except String (Msg MChunk) := do
    98	  let epoch ← jNat (← j.getObjVal? "epoch")
    99	  let payload ← match ← (← j.getObjVal? "kind").getStr? with
   100	    | "none" => pure Payload.none
   101	    | "ct1ackfalse" => pure Payload.none
   102	    | "ct1ack" => pure Payload.ct1Ack
   103	    | "hdr" => pure (Payload.hdr (← parseChunk j))
   104	    | "ek" => pure (Payload.ek (← parseChunk j))
   105	    | "ekct1ack" => pure (Payload.ekCt1Ack (← parseChunk j))
   106	    | "ct1" => pure (Payload.ct1 (← parseChunk j))
   107	    | "ct2" => pure (Payload.ct2 (← parseChunk j))
   108	    | k => throw s!"unknown message kind {k}"
   109	  return ⟨epoch, payload⟩
   110	
   111	/-- A key: `null` or `{epoch, secret}`. -/
   112	def parseKey (j : Json) : Except String (Option Key) := do
   113	  if j.isNull then return none
   114	  return some (← jNat (← j.getObjVal? "epoch"), ← jBytes (← j.getObjVal? "secret"))
   115	
   116	/-- The observation of a step event, with the randomness `r` of its operation. -/
   117	def parseObs (e : Event) (r : Bytes) : Except String (Obs MChunk) := do
   118	  match e.f with
   119	  | "States::send" =>
   120	    if (e.ret.getObjVal? "err").isOk then throw "States::send returned an error"
   121	    return .send r (← parseMsg (← e.ret.getObjVal? "msg")) (← parseKey (← e.ret.getObjVal? "key"))
   122	      (← parseLabel (← (← e.ret.getObjVal? "state").getStr?)) (← jNat (← e.ret.getObjVal? "epoch"))
   123	  | "States::recv" =>
   124	    let m ← parseMsg (← arg e.args 2)
   125	    if (e.ret.getObjVal? "err").isOk then return .recvErr m
   126	    return .recvOk m (← parseKey (← e.ret.getObjVal? "key"))
   127	      (← parseLabel (← (← e.ret.getObjVal? "state").getStr?)) (← jNat (← e.ret.getObjVal? "epoch"))
   128	  | f => throw s!"{f} is not a step event"
   129	
   130	/-- Whether an event ends an operation. -/
   131	def Event.isStep (e : Event) : Bool := e.f == "States::send" || e.f == "States::recv"

   262	                }

   Concrete counterexample: after one real send of `m`, insert `tamper(m, t)` followed by `tamper(t, m)`, where `t` differs in one byte. The second event passes even though the peer never sent `t`, and credits another occurrence of the original `m`. Two receives of `m` now pass delivery.
